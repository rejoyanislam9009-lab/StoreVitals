# StoreVitals

StoreVitals is a read-only WooCommerce store health and diagnostics plugin.

## 1.0.0

- Overall health score and per-area scores.
- Product, inventory, checkout, order, payment, shipping, email sender, HPOS, system, and Scheduled Actions diagnostics.
- CSV export and five-minute local scan caching.
- Bounded product scan (up to 1,000 products per request).
- No telemetry, no external scan service, and no destructive product/order mutation.

Compatibility target: WordPress 6.9+, PHP 7.4+, WooCommerce 10.8+. Metadata tested target: WordPress 7.1 / WooCommerce 11.0.1.

GitHub is the development source. WordPress.org should receive release-ready, human-readable source packages only.
