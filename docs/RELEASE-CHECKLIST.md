# WordPress.org release checklist

- [ ] Final plugin name and slug pass Plugin Check Namer / manual review.
- [ ] PHP syntax passes supported matrix.
- [ ] Official WordPress Plugin Check has no unresolved errors.
- [ ] Runtime test passes on the minimum supported WordPress/PHP/WooCommerce boundary.
- [ ] Runtime test passes on current WordPress/WooCommerce with HPOS enabled.
- [ ] Runtime test passes with legacy order storage where available.
- [ ] Dashboard verified on desktop and mobile widths.
- [ ] Rescan, clear history, CSV, JSON, and print report actions verified.
- [ ] Uninstall removes StoreCheckup history option.
- [ ] Release ZIP contains runtime files only.
- [ ] `readme.txt` stable tag and plugin header version match.
- [ ] WordPress.org icon, banner, and screenshots are prepared separately from the installable ZIP.
